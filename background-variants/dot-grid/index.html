Animated Dot Grid

A subtle dot pattern rendered via body::before with a radial-gradient. The gridShift animation slowly drifts the pattern by 24px, creating a gentle "moving through space" feel.

Key properties: pointer-events: none so content stays clickable. Opacity at 15% in dark mode, 8% in light. No JavaScript, no extra DOM nodes — pure CSS.

How it works

body::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: 0;
  pointer-events: none;
  background-image:
    radial-gradient(
      circle,
      rgba(34, 211, 238, 0.15) 1px,
      transparent 1px
    );
  background-size: 24px 24px;
  animation: gridShift 8s linear infinite;
}

@keyframes gridShift {
  to { transform: translate(24px, 24px); }
}

Integration

Drop the body::before block into src/app/globals.css. Zero imports, zero components, zero JS. Respects light/dark mode via CSS variable theming.
